# Canonical and Hreflang

A plain-language reference on two tags that prevent search problems: the canonical tag, which tells search engines the preferred version of a page when duplicates or near-duplicates exist, and the hreflang tag, which tells them which language and region version of a page to show which users. Written for operators avoiding duplicate-content and international-targeting problems.

## The core idea

A canonical tag points search engines to the single preferred version of a page when the same or similar content is reachable at multiple URLs, so they consolidate signals onto one version instead of splitting them. An hreflang tag tells search engines that a page has versions for different languages or regions, so they show each user the right one. Both solve the problem of search engines getting confused about which of several similar pages to use.

## The stance

This reference treats both tags as plumbing: invisible when right, the cause of confusing ranking problems when wrong. They are not optimization tricks but corrections that prevent search engines from mishandling content that exists in more than one place or language.
